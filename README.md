# Email Categorization Engine (Milestone 2)

## Objective
Develop an NLP-based email classification system using traditional machine
learning models and transformer-based models.

## Models Implemented
- Logistic Regression
- Naive Bayes
- DistilBERT

## Features
- TF-IDF based baseline models
- Fine-tuned DistilBERT transformer
- Performance evaluation using accuracy, precision, recall, and F1-score

## Tools & Libraries
- Python
- scikit-learn
- HuggingFace Transformers
- Datasets
- VS Code

## Results
- Logistic Regression Accuracy: ~0.78
- Naive Bayes Accuracy: ~0.73
- DistilBERT Accuracy: ~0.86
